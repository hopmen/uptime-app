Выйти из аккаунта

Отзывает сессию и удаляет cookie refresh_token. Cookie необязательна; тело запроса отсутствует.

cookie Parameters
refresh_token
string

Необязательная cookie refresh_token=

Responses

/api/v1/auth/logout

Response samples

Content type

Требует cookie refresh_token, выданную при входе или регистрации. Заменяет её новым токеном; тело запроса отсутствует.

RefreshCookie

Responses

  • 401
