# Хуки Codex

Конфигурация находится в `.codex/hooks.json`. После добавления или изменения
хука проверьте и разрешите его в `/hooks` в Codex.

## Защита миграций

`protect-migrations.py` вызывается на `PreToolUse` для `apply_patch`, `Edit`,
`Write` и `Bash`. Файлы из `backend/migrations/`, присутствующие в текущем
`HEAD`, нельзя перезаписывать, редактировать, удалять или переименовывать.
Для изменения схемы создавайте новую миграцию.

Новые миграции разрешено изменять до первого коммита, включая файлы,
добавленные в индекс. Удаление из индекса не снимает защиту файла из `HEAD`.
При ошибке чтения события или Git хук отклоняет вызов инструмента.

Для shell хук проверяет явные пути, шаблоны и операции над родительскими
каталогами; обычное чтение разрешено. Неизвестная команда с путём к защищённой
миграции отклоняется консервативно. Хук не интерпретирует код произвольных
скриптов, динамически вычисленные пути и вызовы других инструментов (например,
MCP редакторов). Это защита от случайных правок, а не изоляция файловой системы.

Проверки в отдельных временных Git репозиториях:

```sh
python3 -B -m unittest discover -s .codex/hooks -p 'test_*.py' -v
```

## ESLint

`frontend-eslint.mjs` запускает `npm run lint` после изменения файлов
фронтенда через `apply_patch`, `Edit` или `Write`.
