# Ка делать commit

1. Показать diff, если пользователь не видел изменения.
2. Сгруппировать изменения по логическим блокам: одно логическое изменение — один коммит.
3. Написать сообщение коммита в заданном формате (перенесённом из прежних правил).
4. Заголовок формулировать в повелительном наклонении; тело добавлять только при необходимости объяснить, почему сделано изменение.
5. Создать коммиты.
