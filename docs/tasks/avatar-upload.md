Контекст (Context)
Мы хотим, чтобы пользователь мог загрузить свой аватар в профиле, и он отобразился у него.

Результат / цель (Objective)
Пользователь заходит в редактирование профиля, нажимает «Загрузить аватар», выбирает изображение подходящего формата (JPEG, PNG, возможно, еще какие-нибудь). После этого нажимает «Выбрать». У нее появляется новый аватар и кнопка «Сохранить», которая обновит этот аватар при нажатии «Сохранить» в профиле пользователя. Сейчас отображается новый аватар, и в панели тоже отображается обновленный аватар.

Границы (Scope)
Мы будем хранить аватары локально в отдельной папке, которая нужно исключить из гит. Из этой же папки мы должны их раздавать на фронтенд.

Проверка готовности (Test)
Тест загрузки аватара: и новое API для загрузки изображения работает.
