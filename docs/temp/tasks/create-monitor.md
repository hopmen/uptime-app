Контекст (Context)
переход к созданию точек мониторинга для сайтов.

Результат / цель (Objective)
пользователь на главном экране нажимает «Добавить сайт», в появившейся форме вводит URL для мониторинга и задаёт частоту опроса(в секундах или минутах или часах), после чего нажимает «Создать». Созданная точка мониторинга отображается на главной странице.

Границы (Scope)
сам процесс мониторинга не реализуется; на этом этапе только создаётся точка. Задача считается выполненной, когда написаны тесты и точка успешно создаётся.

Проверка готовности (Test)
тесты сделаны точка создалась
