# Правила репозитория

## Структура репозитория

В репозитории находятся два независимо запускаемых приложения:

- `backend/` — сервис на Go.
- `frontend/` — веб-приложение на Next.js.

Работайте только в проекте, к которому относится изменение. Не размещайте Go-код в `frontend/`, а веб-код — в `backend/`. Правила и команды для конкретного стека находятся в соответствующем `AGENTS.md` каждого проекта.

## Общие правила разработки

Группируйте предметные изменения по функциям и не включайте несвязанные рефакторинги в одну задачу. Храните секреты в локальных `.env`-файлах; при добавлении новой настройки создавайте очищенный от секретов `.env.example`.

## Правила работы с Git

- Перед началом задачи и при создании коммитов соблюдайте [правила веток и коммитов](docs/commits.md).
- После завершения задачи и проверок соблюдайте [правила подготовки, публикации и слияния Pull Request](docs/pull-requests.md).
